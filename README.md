## 🎯 项目简介

从一个真实痛点出发——

> **"我爸妈攒了一抽屉化验单，看不懂数字，也不知道和上次比是好是坏。"**

Health Timeline 把化验单变成"看得懂的家人健康档案"：

1. 📷 **拍照** 化验单
2. 🔍 **OCR 结构化** 识别检查项与数值
3. 🗣️ **大白话解读** 告诉爸妈"这数字意味着什么"
4. 📈 **跨年份趋势** 和上次比是好是坏
5. 💬 **自然语言问答** 想查什么直接问

### ✨ 设计要点

* 🏥 **本地优先 · 合规边界**：健康数据不出设备，隐私安全
* 👨‍👩‍👧 **家庭档案**：一个 App 管全家人的报告
* ⚡ **Vibe Coding 产物**：从想法到可玩页面，最短 4 小时
